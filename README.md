# Astronomical-Image-Reconstruction
 • Built an image reconstruction framework using Richardson-Lucy deconvolution, boosting PSNR from 30.2 dB to 31.1
 dB and SSIM from 0.71 to 0.77.
 • Applied adaptive regularization with bilateral filtering, refining image clarity while minimizing noise interference.
 • Optimized computational efficiency using Wiener filtering and PSF modeling, achieving a 30% error reduction (RMSE
 from 0.031 to 0.027).
